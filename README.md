# Descripción del Proyecto
Este proyecto consiste en el desarrollo de un sistema integral para la gestión de clientes, servicios y reservas de la empresa Software FJ. El sistema fue desarrollado en Python aplicando Programación Orientada a Objetos, manejo de excepciones y almacenamiento mediante archivos, sin utilizar bases de datos.

# Funciones:
Registro de clientes, Gestión de servicios, Creación de reservas, Manejo de excepciones y errores, Registro de logs, Validación de datos.
